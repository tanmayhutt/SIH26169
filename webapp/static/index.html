Desktop application

This project is delivered as a standalone desktop application, as the problem statement asks. Download it for your computer below, or continue in the browser: this page runs the same engine on the server and needs no installation.

The standalone executable the problem statement asks for: every parameter, real-time pacing at 60 to 250 FPS on your own machine, keyboard control, the full HUD and the user manual built in. No installation and no Python. Extract the archive to a folder you can write to and run FSOC-Tracker.
