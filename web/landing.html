Virtual camera tracking for FSOC coarse alignment

A software stand-in for an FSOC coarse-alignment test bench. It draws a scene with a moving laser beacon, adds the atmosphere, platform and sensor disturbances from the problem statement, and runs a tracker that finds the beacon, measures it to a fraction of a pixel and steers a rate-limited virtual pan-tilt camera to keep it centred. Every run writes its own log and PDF report. Review it either way:

Web app

Runs the same engine on this server and streams the scene, the camera view and the live statistics to your browser. Nothing to install.

  • Pick a scenario or set the parameters, press Start
  • Upload an .mp4 for Benchmark 2
  • Download the report, per-frame CSV and summary at the end
  • One run at a time per server; fewer controls than the desktop version
Open the web app

Desktop application

The standalone executable the problem statement asks for: every parameter, real-time pacing, keyboard control, the full HUD, and the user manual built in.

  • macOS (Apple silicon): download, unzip, run FSOC-Tracker
  • Windows and Linux: build from source with pyinstaller fsoc_tracker.spec; prebuilt archives will be added when built
  • Runs entirely on your machine at 60 to 250 FPS
